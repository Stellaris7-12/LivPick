生活优选 - 高并发秒杀与缓存治理系统优化                                            2025.08 - 2025.10
项目描述：基于本地生活优惠场景，对传统单体点评类项目进行并发链路重构，围绕“秒杀下单、库存一致性、缓存治理、超时关单”四条核心链路，落地 Redis、Lua、Kafka、Redisson 等中间件能力，重点解决高并发下的超卖、重复下单、异步削峰和缓存穿透问题。
技术栈：Spring Boot + MySQL + Redis + MyBatis-Plus + Lua + Kafka + Redisson
主要工作：
1. 重构秒杀主链路，采用“Redis + Lua 资格校验与库存预扣 + Kafka 异步落库”模式，将高并发请求前置拦截在 Redis，数据库只承担最终库存扣减和订单落库压力。
2. 设计一人一单与库存一致性保障方案，使用 Redis 用户资格集合、Consumer 侧用户维度 Redisson 锁、MySQL 唯一索引三层兜底，避免重复下单和超卖，并将业务语义收敛为“超时取消只释放库存，不恢复抢购资格”。
3. 完成未支付订单自动关闭能力，基于 Redisson 延迟队列投递关单消息，结合 Spring 定时扫描做兜底补偿，并通过订单状态条件更新保证支付与关单并发竞争下的状态正确性。
4. 补齐异步链路可靠性，针对 Kafka 发送异常引入 Redis 待发送登记和后台补发任务，避免“接口返回失败但消息可能已入队”导致的资格误回滚问题。
5. 优化缓存治理链路，在店铺详情查询中接入布隆过滤器与缓存空值拦截无效请求，使用逻辑过期降低热点 Key 重建抖动；在写路径采用“更新数据库后删除缓存”，并通过 Kafka + 延迟退避任务补偿缓存删除失败场景。
6. 基于 Redis GEO 构建附近店铺检索能力，结合 RedisIdWorker 生成趋势递增全局订单 ID，支撑高并发下的近场检索与订单创建。
